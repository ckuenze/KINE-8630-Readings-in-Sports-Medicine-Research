# PA Processing Dashboard

Load ActiGraph 60-second epoch exports, validate wear time with the Choi (2011) algorithm, apply your own valid-day criteria, and compare activity intensity across four count-based cutpoint sets and Tudor-Locke cadence thresholds.

- **Methods topic:** Accelerometer data processing, wear-time validation, and intensity classification
- **Course:** KINE 8630

## Learning objectives

After using this tool, students should be able to:

- Explain how the Choi (2011) algorithm separates non-wear from sedentary wear time, and where it can misclassify.
- Apply valid-day and valid-week criteria (minimum hours per day, minimum days, minimum weekend days) and describe how they change who is included in an analysis.
- Compare MVPA estimates from Freedson (1998), Freedson VM3 (Sasaki 2011), Troiano (2008), and Evenson (2008) cutpoints, and explain why they differ.
- Compare count-based and cadence-based (Tudor-Locke) intensity classification.
- Describe how counts and steps are generated by the device, and the limits that follow (filtering, the plateau effect, and sampling-rate dependence).

## How to use it

Open `index.html` in a web browser.

1. Set the valid-day criteria in the bar at the top (defaults: 10 h/day, 4 days, 1 weekend day).
2. Click **Add File(s)** and choose one or more 60-s epoch CSV files. The example files in [`example-data/`](example-data/) work out of the box.
3. For each participant, review the day-by-day wear table, the intensity summaries (per day or projected per week), the cadence summary, and the minute-by-minute activity timeline.

Files stay in your browser and are never uploaded.

## Input format

ActiLife "Data Scoring Details" CSV export with 60-s epochs: one metadata line, one header row, then one row per minute with `date, epoch, axis1, axis2, axis3, vm, steps` (inclinometer columns are optional). Missing epochs are filled as device-off gaps.

## Details

- **File:** `index.html` (standalone; loads Chart.js from cdnjs)
- **Wear-time validation:** Choi et al. (2011): 90 min of consecutive zero counts on Axis 1, allowing up to 2 min of non-zero counts if flanked by 30 min of zeros on each side.
- **Author:** Christopher Kuenze, PhD, ATC, FNATA
- **Last updated:** November 2026
